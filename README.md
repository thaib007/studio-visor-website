## Overview

Studio Visor is a modern, dark cinematic website for a YouTube content production studio based in Uttara, Dhaka. It showcases **video editing**, **high-CTR thumbnails**, and **full automation** services for creators and brands worldwide.

Built with **Vite + React + Tailwind + Framer Motion + Three.js** for smooth animations and a premium glassmorphism experience.

## Tech Stack

- **Frontend:** React 19 + TypeScript
- **Build:** Vite
- **Styling:** Tailwind CSS
- **Animation:** Framer Motion
- **3D:** Three.js + React Three Fiber
- **Deployment:** GitHub Pages
